# ComputePilot v0.6 规划

> **方向**: 会话可观测性与 API 化 — 让保存的会话、运行数据可查询、可脚本化

---

## 背景

v0.5 引入了 Conductor 会话持久化（`--from-session`）和 Dashboard，但：
- 保存的会话没有 CLI 入口可见——用户不知道有哪些会话可恢复
- 运行数据只有 HTML 页面，无法被脚本/外部工具消费
- `cpilot dag` 不支持 SVG 输出（Dashboard 有渲染器但 CLI 用不到）

## 目标

### 1. 📋 `cpilot sessions` 命令组

```bash
cpilot sessions list            # 列出已保存会话（id/阶段/意图/时间）
cpilot sessions show <id>       # 查看完整对话历史 + 提取的意图
cpilot sessions clean           # 清理 30 天前的旧会话
```

### 2. 🔌 JSON API 端点（Dashboard 同源）

```
GET /api/runs                    # 运行列表
GET /api/run/{id}                # 详情：元数据 + 任务 + 事件 + workflow 结构
GET /api/run/{id}/events?after=N # 增量事件轮询（支持实时 tail 客户端）
```

- 运行详情页新增 Events 区块（最近事件表）

### 3. 🖼️ `cpilot dag --format svg`

- 将 webui 的分层 SVG 渲染器提取为共享模块 `cli/svgdag.py`
- `--output/-o` 写入文件；节点支持状态着色（配合 --run-id）

---

## 优先级

| P | 工作 | 验收标准 |
|---|---|---|
| P0 | `sessions list/show/clean` | 单测覆盖三子命令 |
| P0 | JSON API ×3 | TestClient 测试；events 支持 after 游标 |
| P1 | `dag --format svg [-o]` | 输出合法 XML；环输入返回错误 |
| P2 | 覆盖率 ≥90% | engine 异常路径 / probe 边界补测 |

## 明确不做（v0.7+）

- 云执行器（需真实云环境验证）
- WebSocket 推送（轮询满足当前规模）
- 多租户 / 认证
