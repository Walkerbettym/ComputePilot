# ComputePilot v0.4 规划

> **方向**: 从"能跑真实用例"到"生产可用" — 稳定性、CLI 集成、监控生态

---

## 三大目标

### 1. 🎯 全覆盖测试（coverage ≥ 80%）

当前 67%。补齐：
- CLI 命令测试（排除 Tyver+3.14 问题后）
- `runtime/probe.py` 边界（GPU 检测、大目录扫描）
- `runtime/engine.py` 异常路径（看门狗超时、deadlock
- `agent/conductor.py` 多轮边缘情况

### 2. 🔗 全链路 CLI 集成

当前 `plan --interactive` 只能谈话，不能执行。v0.4：

```bash
# 一次完成：谈话 → 批准 → 执行
cpilot run --interactive "CFD simulation of cylinder at Re=1000"

# or 从继续上次对话
cpilot run --from-session <session_id>
```

- `run --interactive` — 集成 Conductor + Engine
- `run --from-session` — 从现有对话继续
- `status --live` — Execution Sentinel 实时进度条

### 3. 🐳 真实 Docker CI

- GitHub Actions 加 Docker executor 测试（`test_docker_executor.py`）
- 将 `openfoam_cylinder` 作为定期集成测试运行
- 确保非 Docker 环境下测试跳过但不报错
