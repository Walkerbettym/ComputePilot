# ComputePilot v0.5 规划

> **方向**: 从"生产可用"到"规模与领域生态" — DAG 可视化、HPC 领域 Skill、日志流

---

## 背景

v0.4 已交付：CLI 全链路集成（`--interactive` / `--from-session` / `--live`）、Web Dashboard、
WorkspaceManager、覆盖率 87%（CI 阈值 80）。

spec.md 遗留承诺：
- **NG-5** — OpenFOAM / GROMACS / LAMMPS 等复杂领域 Skill（原定第二阶段）
- **R2 风险对策** — 真实 Slurm 集群冒烟脚本（独立于 CI）

---

## 目标

### 1. 📊 DAG 可视化（`cpilot dag`）

```bash
cpilot dag workflow.yaml              # ASCII 树（终端友好）
cpilot dag workflow.yaml --format mermaid   # mermaid 文本（GitHub/Markdown 可嵌入）
cpilot dag workflow.yaml --format json      # 机器可读（供 Web UI 用）
```

- 复用 `workflow/dag.py` 拓扑信息；标注每任务 type/resources/预计成本
- Web Dashboard 运行详情页嵌入 mermaid 渲染

### 2. 🧬 HPC 领域 Skill（NG-5 兑现）

| Skill | 词汇表 | 参数约束 | 示例 |
|---|---|---|---|
| `openfoam` | 求解器/湍流模型/边界类型 | Re 范围、网格要求 | openfoam_cylinder |
| `gromacs` | 分子/力场/系综 | 温度范围、步数约束 | — |
| `lammps` | 势函数/系综/材料 | 原子数上限 | — |

- 对齐 population_genetics skill 的结构：vocabulary_mappings + parameter_constraints
  + optimization_strategies + error_handling
- Conductor 路由自动识别领域查询

### 3. 📡 日志流（`cpilot logs --follow`）

- tail -f 式跟踪 task_events 新增行（1s 轮询 SQLite）
- `--task` 过滤与 `--follow` 组合可用

### 4. 🏛️ Slurm 冒烟脚本（R2 对策）

- `scripts/slurm_smoke.sh` — sbatch/sacct/scancel 全链路真实验证
- 独立于 CI；输出 PASS/FAIL 矩阵供集群管理员使用

## 优先级

| P | 工作 | 估计 | 验收标准 |
|---|---|---|---|
| P0 | `cpilot dag` 三格式输出 | 3 天 | 单测覆盖三格式；e2e 校验 mermaid 语法 |
| P0 | HPC Skill ×3 | 1 周 | 各 skill 单测 ≥5；Conductor 路由测试 |
| P1 | `logs --follow` | 2 天 | 集成测试：写入事件后 follow 捕获 |
| P1 | Slurm 冒烟脚本 | 2 天 | FakeSlurm 上演练通过；README 使用说明 |
| P2 | Dashboard mermaid 图 | 3 天 | 运行详情页显示任务依赖图 |
| P2 | 1000-task 调度基准 | 1 天 | perf marker：< 1s 调度开销 |
