# ComputePilot v0.3 规划

> **方向**: 从"能跑"到"真正能用" — CLI 体验、K8s 执行器、论文完整闭环

---

## 三大方向

### 1. 🚀 执行器：Kubernetes（论文对齐）

论文的 Deployment Service + HyperFlow on K8s。我们需要：
- `executors/kubernetes.py` — K8s 执行器（namespace/pod/PV）
- `cli/commands/deploy.py` — 部署命令
- 数据暂存（download input data to PV）
- 资源探测（实际数据大小、vCPU）
- 集成 Deferred Generation（探测→最终 DAG）

### 2. 🎮 CLI 体验：多轮模式 + 流水线集成

- `cpilot plan --interactive` — Conductor 多轮 CLI
- `cpilot run --from-plan` — 从 Conductor 会话直接执行
- Execution Sentinel → `cpilot status --live` 实时进度
- `cpilot probe` — 探测环境命令

### 3. 🧪 代码质量

- 覆盖率 ≥ 80%（当前 69%）
- 补齐 engine.py 剩余分支测试
- 补齐 scheduler.py 边界测试
- perf 基准加入 CI
