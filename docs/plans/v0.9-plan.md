# ComputePilot v0.9 规划

> **方向**: 复现性闭环与编程接口 — 让"可复现"可验证、让引擎可被 Python 直接调用

---

## 背景

项目的核心承诺是 **Everything Reproducible**：
- Demo 4 已验证"相同输入→相同 sha256"，但用户缺少一键对比两次运行的工具
- 制品注册后没有导出命令，取回结果要手工翻目录
- 科学用户活在 Jupyter 里——所有能力都只能走 CLI 子进程

## 目标

### 1. ✅ `cpilot verify <run_a> <run_b>`（P0）

逐项对比两次运行，输出差异矩阵：

| 对比项 | 来源 |
|---|---|
| Workflow SHA256 | runs.workflow_sha256 |
| 任务状态/退出码 | task_states |
| 制品 checksum | artifacts（按路径对齐） |

- 全部一致 → exit 0（REPRODUCIBLE）；任一差异 → exit 1；运行不存在 → exit 2
- `--json` 输出机器可读结果

### 2. 🐍 Python API 层 `computepilot.api`（P0）

```python
from computepilot import api

run = api.run("wf.yaml", params={"epochs": 50})     # 阻塞至完成
print(run.status, run.id)
api.status(run.id)          # dict
api.list_runs(limit=10)
api.artifacts(run.id)       # 注册制品元数据
api.report(run.id)          # 生成 manifest.json + report.md
api.resume(run.id, "wf.yaml")
```

- 同步函数内部桥接 asyncio；`state_dir` 参数支持嵌入隔离
- Notebook / 脚本无需子进程即可驱动引擎

### 3. 📤 `cpilot artifacts get`（P1）

```bash
cpilot artifacts get RUN_ID -o ./results      # 导出全部制品并校验 sha256
cpilot artifacts get RUN_ID --task train -o . # 仅某任务
```

- 导出时重算 checksum 与注册值比对，不一致即告警

## 验收

| 项 | 标准 |
|---|---|
| verify | 相同内容 exit 0；篡改制品 exit 1；缺运行 exit 2；--json 结构完整 |
| api | run/status/list/artifacts/report/resume 全链路单测通过 |
| artifacts get | 导出文件字节一致；checksum 不匹配时告警 |

## 明确不做

- 远程存储后端（S3/GCS）
- 工作流 include 组合（v1.0 候选）
