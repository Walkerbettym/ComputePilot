# ComputePilot v0.7 规划

> **方向**: 正确性与完整性收尾 — 溯源报告补全、实时进度修复、技能检视

---

## 背景

代码审查发现三处"声明了但未兑现"的缺陷：

1. **`cpilot report` 的报告永远写 "*No artifacts registered.*"** — 即使制品已注册
2. **`manifest.json` 的 `artifacts` 字段恒为空数组** — 违背 "Everything Reproducible" 原则（P3）
3. **`status --live` 找不到任务总数时硬编码 100** — 进度百分比失真

## 目标

### 1. 📜 溯源报告补全（P0）

- `ProvenanceBuilder.build_manifest(artifacts=[...])` 接受 ArtifactStore 查询结果，
  manifest.artifacts 输出 `{id, task_id, path, type, sha256, size}`
- `report.md` 渲染制品表（路径/sha256/大小），无制品时才写 No artifacts
- spec.md P3 验收：每次 run 可生成含 checksum 的完整 manifest

### 2. 📊 `status --live` 真实总数（P0）

- 优先 config.total_tasks → 其次 COUNT(DISTINCT task_id) FROM task_states → 最后才用 100

### 3. 🔍 `cpilot skill show <name>`（P1）

- 以 YAML 输出技能完整定义，便于领域技能编写者参考/复制结构

### 4. 💾 `plan --interactive` 会话保存（P1）

- 与 `run --interactive` 对齐：对话结束自动保存会话并提示恢复命令

### 5. 🧪 覆盖率 ≥90%（P2）

- engine 异常路径、probe 边界、planner 分支

## 验收

| 项 | 标准 |
|---|---|
| 制品溯源 | 注册制品后 report.md 含表格；manifest.artifacts 非空且 checksum 一致 |
| live 进度 | 仅 task_states 数据时进度条按真实分母计算 |
| 覆盖率 | ≥90%，CI 阈值同步上调 |
