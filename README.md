# ComputePilot

> An open-source agentic workflow runtime for reproducible scientific computing.

**Agent + Workflow + Reproducibility**

ComputePilot lets researchers describe computational experiments in natural language, then generates executable, verifiable, resumable, and reproducible workflows that run on local machines, Docker, or Slurm clusters.

Three core capabilities:

```
Understand → Plan → Execute (Reliable Runtime) → Reproduce (Artifacts + Provenance)
```
